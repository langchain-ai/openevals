## Chosen Domain & Dataset

**Domain:** UX and Product Design knowledge — questions a designer or design team might ask about usability principles, accessibility standards, design systems, user research methods, and platform guidelines.

**Sources:** Questions and reference answers are based on established UX literature including Nielsen Norman Group's usability heuristics, WCAG 2.1 guidelines, Apple's Human Interface Guidelines, and standard UX research methodology textbooks.

**What makes a good example:** Each example has a clear question (input) and a factual reference answer (output) that can be objectively verified. Questions range in difficulty from easy (UX vs UI distinction) to hard (specific WCAG contrast ratios, SUS scoring methodology).

**Dataset name in LangSmith:** `ux-design-knowledge-qa`  
**Dataset size:** 15 examples across 11 UX categories

## Approach Overview

1. **Dataset Creation** — Built 15 Q&A pairs covering usability heuristics, WCAG accessibility, design systems, user research, interaction design, information architecture, prototyping, cognitive psychology, evaluation methods, and platform guidelines. Uploaded to LangSmith as a reusable dataset.
2. **Target Function** — Implemented a `@traceable` function that sends each question to GPT-4o-mini with a UX-expert system prompt and returns the model's answer.
3. **Evaluator** — Built an LLM-as-judge correctness evaluator that compares the model's answer against the reference answer, scoring 1 (correct and complete) or 0 (factual errors or missing critical information).
4. **Evaluation Execution** — Ran the evaluation via `langsmith.evaluate()` with concurrency of 2, results automatically traced in LangSmith.
5. **Analysis** — Extracted scores, calculated pass rates, identified failure patterns, and saved results to JSON.

## How to Run

```bash
# 1. Install dependencies
pip install openai langsmith langchain-openai openevals python-dotenv

# 2. Create .env file with your keys
echo "OPENAI_API_KEY=your-openai-key" > .env
echo "LANGSMITH_API_KEY=your-langsmith-key" >> .env

# 3. Run the evaluation
python langsmith_evaluation.py
```

The script will:
- Create the dataset in LangSmith (or skip if it already exists)
- Generate answers for all 15 questions using GPT-4o-mini
- Judge each answer against the reference
- Print a summary and save results to `evaluation_results.json`
- All traces are visible in your LangSmith project: `ux-design-eval`
